---
title: 3. AWS の合鍵（認証情報）を設定する
---

Claude は AWS の上で動いています。あなたのチーム用の AWS アカウントを使うために、「合鍵」を設定します。

> Workshop Studio へのログイン方法は、当日配布される AWS のマニュアルを見てください。ここでは **ログインした後** から説明します。

## 3-1. Workshop Studio で認証情報を表示する

1. 左のメニュー「**AWS account access**」→「**Get AWS CLI credentials**」をクリック ①
2. 一番左の「**Linux or macOS (bash)**」タブを選ぶ ②
   - **Windows の人もこのタブ** です（理由は下のコラム）
3. 右上の 📋 **コピーボタン**を押す ③

<!-- TODO: スクリーンショット（①②③ を番号付きで囲む。秘密部分は端まで塗りつぶし） -->

:::tip[☕ Coffee Break：Windows なのに「macOS」のタブでいいの？]
いいんです。この 4 行は PowerShell に打ち込むのではなく、次の手順で **`.env` というメモ（テキストファイル）に貼るだけ** だからです。
全員が同じ形で貼ると、見本（`.env.example`）とも同じ見た目になって確認しやすくなります。
（もし PowerShell のタブを貼ってしまっても、ちゃんと読めるので大丈夫です）
:::

:::danger[マウスで選んでコピーしない]
中身がとても長く、画面の右にはみ出しています。マウスで選ぶと途中で切れてしまいます。**必ず 📋 ボタン**を使ってください。
:::

## 3-2. `.env` ファイルを作って貼り付ける

2章で移動したフォルダーで、次の 1 行を実行します。メモ帳（テキストエディット）が開きます。

- Mac
  ```bash
  cp .env.example .env && open -e .env
  ```
- Windows（PowerShell）
  ```powershell
  copy .env.example .env ; notepad .env
  ```

開いたファイルの **一番下の 4 行（`export AWS_...` の行）を消して**、3-1 でコピーした内容を貼り付けて保存します。
貼った後も `export AWS_...` で始まる 4 行になっていれば OK です。

:::tip[☕ Coffee Break：認証情報は「合鍵」]
この 4 行は、あなたのチームの AWS アカウントを使うための**合鍵**です。
- 人に見せない・SNS に貼らない
- GitHub に上げない（このサンプルは `.env` を自動で除外する設定になっています）
- Claude にも中身は見せない設定にしてあります。だから貼り付けは自分でやります
:::

:::tip[☕ Coffee Break：なぜ期限切れになるの？]
この合鍵は「一時的な合鍵」で、時間がたつと使えなくなります（なくしても被害が広がらないように）。
エラーが出たら、3-1 からもう一度コピーして貼り直せば OK です。
