## 4-1. 起動する

2章のフォルダーにいることを確認して:

- 🛡️ 安全コース
  ```bash
  sbx env run
  ```
  - 最初に「計画（plan）」が表示されます → 内容を確認して**承認**
  - 砂場の準備と Node.js のインストールで 1 分ほどかかります（`✅ Node.js … を使えるようにしました` が出れば OK）
  - 2回目からは同じ砂場に入るだけなので、すぐ起動します
- 🚀 直接コース
  ```bash
  claude
  ```

:::caution[必ずサンプルのフォルダーで起動する]
別のフォルダーで起動すると、AWS の設定が読み込まれず、ログイン画面が出てしまいます。

## 4-2. 最初に聞かれること

1. **「このフォルダーを信頼しますか？」** →「はい（Yes）」
2. **AWS 用のプラグイン（aws-core）を入れる**
   - 🛡️ 安全コース … `sbx env run` が自動で入れてくれます（何もしなくて OK）
   - 🚀 直接コース … Claude の入力欄で `/plugin` →「Errors」タブで `aws-core` を選んで **Enter**（または `/exit` してから次の 1 行）
     ```
     claude plugin install aws-core@anthropic-plugin-directory --scope project
     ```
3. （🛡️ 安全コース）右下に **`Update installed · Restart to update`** と出たら → `/exit` で終了して、もう一度 `sbx env run`

:::tip[☕ Coffee Break：プラグインって何？]
Claude に「AWS の専門知識」を足す追加パックです。CDK でのデプロイや Lambda、Bedrock の使い方などを、AWS 公式の手順に沿って進めてくれるようになります。
:::

:::tip[☕ Coffee Break：なぜ「信頼しますか？」と聞かれるの？]
このフォルダーには、Claude 向けの設定（使う AI の種類、合鍵の読み込み方など）が入っていて、起動時に自動で実行されます。
知らない人からもらったフォルダーでは「はい」を押さないようにしましょう。
:::

## 4-3. 話しかける

```
こんにちは
```

返事が来たら成功です 🎉 画面の上の方に `Amazon Bedrock` と表示されていれば、チームの AWS アカウントで動いています。

:::tip[☕ Coffee Break：Claude はどこで動いているの？]
あなたの PC の中ではなく、AWS のデータセンター（アメリカ東部）で動いています。
あなたが打った文章がインターネット経由で届き、答えが返ってきます。だから、ネットにつながっていないと使えません。
:::

:::note[画面の一番下の「〜 mode」表示]
`Shift + Tab` を押すたびに、Claude の動き方（モード）が切り替わります。
🚀 直接コースでは、**コマンドの前に確認してくれるモード**（一番下に何も出ていない状態）がおすすめです。

:::tip[☕ Coffee Break：「AI に PC を触らせる」とは]
Claude はファイルを作ったり、コマンドを実行したりできます。🚀 直接コースでは、大事な操作の前に「実行していいですか？」と聞いてきます。
