---
title: 7. インターネットに公開する（デプロイ）
---

```
アプリを AWS にデプロイして
```

Claude が次を実行します（`.env` の合鍵を使います）。

| コマンド | 意味 | 時間 |
|---|---|---|
| `npm run bootstrap` | AWS アカウントの初期準備（**チームで最初の 1 回だけ**） | 約 1 分 |
| `npm run deploy` | 地図画面（クライアント）とサーバー（Lambda）をまとめて公開 | 約 5 分 |

終わると最後に **`AppUrl = https://〜.cloudfront.net/`** と表示されます。これがあなたのアプリの住所です。スマホでも開けます 📱

- 3D 版を公開したいときは `npm run deploy:navara`（2D 版と入れ替わります）
- 片付けるときは `npm run destroy`

```
CloudFront（AppUrl）
 ├─ /        → S3（地図画面＝クライアント）
 └─ /api/*   → Lambda（サーバー → Bedrock）
```

:::caution[公開 URL の扱い]
AppUrl を知っている人は誰でも Claude に質問できます。SNS などには貼らないでください（チームの AWS で AI が使われます）。
:::

:::tip[☕ Coffee Break：待っている 5 分間に何が起きているの？]
CloudFront（世界中に配置されたコピー置き場）に、あなたの地図画面を配っています。だから少し時間がかかります。
:::

:::tip[☕ Coffee Break：デプロイって何？]
手元の台所で作った料理を、お店のメニューに載せることです。
localhost は「自分の台所」、デプロイ後の URL は「お店の住所」。住所がわかれば、誰でも食べに来られます。
:::

:::tip[☕ Coffee Break：ハッカソンが終わったらどうなる？]
Workshop Studio の AWS アカウントは、イベント終了後に **アカウントごと消えます**。公開した URL も使えなくなります。
作ったコードを残したい人は 8 章で GitHub に保存しましょう。
:::
