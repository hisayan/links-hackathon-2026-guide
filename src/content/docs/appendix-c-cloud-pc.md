## どんなとき？

- 会社の PC で、ソフトのインストールや設定の変更ができない
- 自分の PC の中身を、AI に絶対に触らせたくない

そんなときは、**AWS の上に「仮想の Windows PC」を 1 台借りて**、その中で 🚀 直接コースを進める、という手があります。

```
あなたの PC                    AWS（チームのアカウント）
┌──────────┐   画面だけ    ┌────────────────────┐
│ ブラウザ  │ ◀──────────▶ │ 仮想の Windows PC   │
│ or RDP   │   やりとり    │  ├ Claude Code      │
└──────────┘               │  ├ Node.js          │
                           │  └ サンプル          │
                           └────────────────────┘
```

あなたの PC に届くのは「画面」だけです。仮想 PC がまるごと **AI の遊び場** になるので、AI があなたの PC の中身を見ることはありません。

## ざっくりした流れ

1. AWS マネジメントコンソールで **EC2** を開く
2. 「インスタンスを起動」で **Windows Server（日本語版）** を選んで起動する（大きさは `m7i.large` くらい）
3. 接続する
   - ブラウザから：EC2 の「接続」→「RDP クライアント」→ **Fleet Manager** で接続
   - アプリから：Windows は「リモート デスクトップ接続」、Mac は「Windows App」
4. 仮想 PC の中で、[1-B](01-prepare.md#1-b--直接コースの準備) から順に進める

## 気をつけること

- **使い終わったら停止・削除する** … 動かしている間はお金がかかります（目安：1 時間あたり数十円）
- **日本語入力・コピー＆ペースト** … ブラウザから接続すると、うまくいかないことがあります。RDP アプリのほうが快適です
- **イベントが終わると消えます** … Workshop Studio のアカウントごと、仮想 PC も消えます。作ったものは [8章](08-github.md) で GitHub に保存しましょう

:::tip[☕ Coffee Break：クラウドで「PC を借りる」？]
クラウドは、サーバーだけでなく **PC そのもの** も借りられます。
あなたが見ているのは遠くの PC の「画面」で、計算もファイルも全部 AWS のデータセンターの中にあります。
だから手元の PC が古くても、速い PC を使っているのと同じように作業できます。
:::
