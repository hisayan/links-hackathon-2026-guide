## ここまで読んでくれて、ありがとう！

こんにちは、このガイドを書いた久田です。
長いガイドを最後まで読んでくれて、ほんとうにありがとうございます 🙌

## ハッカソン、大好きなんです

わたしはハッカソンみたいな場所が大好きです。

エンジニア、デザイナー、学生さん、行政の人、街のことにくわしい人……。
ふだんは出会わないような、いろんな人がひとつの部屋に集まって、テックで遊びながら、2日間で新しいものを作っちゃう。
そんなワクワクする場所って、なかなかないですよね。

## 今回の環境、ほんとに「めっちゃいい」です

今回のハッカソンは、道具がとにかく豪華です。

- 🗂️ **LINKS のオープンデータ**：国がちゃんと整えた、使えるデータがたくさん
- ☁️ **AWS の最新の環境**：Claude Code と Amazon Bedrock で、AI に手伝ってもらいながら作れる
- 🗺️ **Navara**：最新の WEB GIS に使えるライブラリで、地図や 3D の街がすぐに動く

しかも、それぞれに**プロがサポートについています**。
困ったら、すぐそばに聞ける人がいる。こんな恵まれた環境、なかなかないですよ！

## 当日の、ちょっとしたコツ

- **完ぺきじゃなくて大丈夫。** 動くものが 1 つあれば、それだけでじゅうぶんすごいです
- **AI にどんどん頼っちゃおう。** 「こんなことできる？」と聞くだけで、意外とできちゃいます（[プロンプト集](prompts.md) もどうぞ）
- **うまくいかないのも楽しもう。** エラーが出たら、それもネタです。[困ったとき](troubleshooting.md) も見てみてね
- **ひとりで悩まないで。** 5 分悩んだら、まわりの人やメンターに声をかけてください

## さいごに

ぜひ、たのしんで作って、わたしたちを**おどろかせてください**！
会場で見かけたら、気軽に声をかけてくださいね。どんな小さなことでも、相談大歓迎です 😊

当日、みなさんに会えるのを楽しみにしています！
